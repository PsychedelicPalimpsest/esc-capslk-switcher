# Capslock-Escape Switcher

A Mincraft mod to swap escape and capslock. Available for Fabric and NeoForge mod loaders.

Download a compiled build [here](https://legacy.curseforge.com/minecraft/mc-mods/escape-caps-lock-swapper).

**Q: Why does this mod exist?**

Minecraft ignores system-wide key re-mapping, as it reads the raw keyboard inputs. This means it also ignores the switching of caps lock and escape done by many [neovim](https://neovim.io/) users. Even if you don't use neovim, I still highly recommend doing this.
